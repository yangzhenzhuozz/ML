# 序：把黑盒砸碎，将逻辑焊死

如果你翻开过市面上大多数关于机器学习或深度学习的教材，你大概率经历过这样的痛苦：
一上来，作者会给你画一张极其清爽的计算图，告诉你这是神经网络。紧接着，在最核心、最需要硬核数学支撑的“反向传播（Backpropagation）”章节，作者会突然拍脑袋扔出几个精美、高大上的矩阵大括号，或者直接甩出几行带有雅可比矩阵转置连乘的公式，然后轻飘飘地留下一句口诀：**“由外向内，层层求导，同路相加，异路相乘。”**

这种“抛公式、给口诀”的糊弄学，往往让我们产生一种“看懂了”的幻觉。可一旦你想深入一些细节，或者试着自己去推导一个稍微奇葩一点的自定义网络结构时，你的思维就会瞬间死机——因为你根本不知道这些加号和乘号，在底层的微积分里究竟是怎么持证上岗的。

**我不喜欢被糊弄**

这就是我决定写这本书的根本原因。在这本书里，我做出了一个最消耗体力和心智的决定：**把每一个高深公式的推导、每一个隐藏在底层的微积分零件，全部彻底揉碎，完全暴力展开展示在纸上。**

为了磨好反向传播这把“快刀”，我们会在数学基础章节里死磕高等数学最核心的定理。我们会去用放大镜审查全微分的每一次动态逼近，去揪出那些在二元战场上企图钻空子的“恶魔路径”，把偏导连续性的每一重保险在底层彻底焊死。

当你帶著這把毫无逻辑断层的微积分利刃，去宰多层感知机（MLP）的反向传播时，你会迎来前所未有的顶级认知高潮：
* 你会亲眼看到，那些满屏幕眼花缭乱的公共前缀，是如何因为人类“不想重复计算”的懒人刚需，自然而然地凝聚成统一的符号——**敏感度（$\delta$）**；
* 你会真正看穿，为什么在网络拓扑结构的分叉路口**偏偏是做“加法”**，因为那根本不是什么玄学口诀，而是多元函数全增量在代数层面上的必然结果；
* 你更会惊喜地发现，我们推导出的通用敏感度规则，在咽喉要道（未激活状态 $z$）上实现了**完美的工程解耦**。它不仅能暴打传统的线性网络，还能顺手降维打击未来所有前沿的非线性架构。

这本书不是为了让你死记硬背几行 PyTorch 的代码，而是为了带你退回到最纯粹的数学基石上，拆掉所有挡在数学和工程之间的“黑盒墙”。

**顺着变量的代数流动，我们要做到真正的一看就懂、一眼看穿本质。**

祝你在这场死磕底层的思维重塑之旅中，玩得痛快。

—— 作者
