# 调试技巧

## 模型总是输出样本的频率

假设现在我们有一个训练样本，里面有c种类别，分布如下：

|      | $c_1$ | $c_2$ | $c_3$ | $\cdots$ | $c_n$ |
| ---- | ----- | ----- | ----- | -------- | ----- |
| 频率 | $p_1$ | $p_2$ | $p_3$ | $\cdots$ | $p_n$ |

如果模型对于任意输入，总是也输出

|      | $c_1$ | $c_2$ | $c_3$ | $\cdots$ | $c_n$ |
| ---- | ----- | ----- | ----- | -------- | ----- |
| 频率 | $p_1$ | $p_2$ | $p_3$ | $\cdots$ | $p_n$ |

说明模型已经退化成一个标签频率模型，因为XY两个随机变量相互独立的情况下有

$$
P(B|A)=\frac{P(A)P(B)}{P(A)}=P(Y)
$$

此时前置事件A对事件B没有任何影响。从统计学的角度来说，如果训练样本本身没有除了概率之外的其他信息（真随机），这也是理论上的最优解。但是实际上我们的样本都是有意义的，所以这种训练结果往往不是我们想要的，我们实际追求的是互信息最大化
