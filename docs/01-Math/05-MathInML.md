# 机器学习中的数学技巧

虽然根据通用近似定理，在适当条件下，单隐藏层的网络只要有足够多的神经元就能以任意精度逼近目标函数，但这只说明模型具有相应的表达能力，并不保证训练算法一定能找到理想参数。loss函数决定了在训练时候的模型优化目标，如果损失函数的目标和我们的预测目标不一致，反而会导致模型远离最优参数。而激活函数则会影响模型的表达范围和优化难度。所以在机器学习中，我们通过如下技巧选择函数

## 损失函数的选择

损失函数就是我们针对训练目标的最大似然估计，一般基于如下选择

### MSE

假设模型输出和真实样本之间的误差服从正态分布。因为模型的输出 $\hat y$ 和样本 $y$，因为模型本质是一个并不会存在误差的确定函数 $f$ ，这里的误差本质来源是现实世界的真实值和我们采样数据 $y$ 的误差（传感器、人工标注误差，或者是我们暂时未发现的隐藏变量）。此时模型输出就直接是预测结果。

### BCE

假设任务的目标变量 $y \in \{0, 1\}$ 服从伯努利分布。通过最大化伯努利分布的似然函数，自然就会推导出 BCE 损失函数。此时模型输出不是预测结果，而是预测结果的概率。

### CCE

假设任务的目标变量服从多项分布。通过最大化多项分布的似然函数，就会推导出 CCE 损失函数。此时模型输出不是预测结果，而是预测结果的概率。BCE本质上是CCE的一种特化，并且通过信息论的相关知识知道，只要我们的训练数据和模型输出数据都是概率时，就可以使用交叉熵作为损失函数。

## 输出层激活函数的选择

根据我们对值域的需求，通常做如下处理

### 线性输出

如果我们的目标是输出整个实数 $R$，一般会直接令输出层输出线性值，即不在神经元外层包裹非线性激活函数。通常在数值预测中使用。

### sigmoid

如果我们需要输出一个 $(0,1)$ 区间的值，则使用 sigmoid 做输出层激活函数。通常在二分类任务中使用。

### tanh

如果我们需要输出一个 $(-1,1)$ 区间的值，则使用 tanh 做输出层激活函数。tanh 函数的值域在 $(-1,1)$，并在在0点处具有较大梯度。相比于 sigmoid，tanh 利于下一层的输入保持0中心化，避免全局同向偏置。虽然 $\text{sigmoid} \times 2 -1$ 之后也能满足值域在 $(-1,1)$、0中心化等特点，但是其在0点处的导数没有tanh大，在多层嵌套中更容易丢失梯度，比如在RNN中因为等效深度过深，sigmoid函数的效果相对来说没有tanh效果好。

### softmax

如果我们需要输出n个数值，并且希望这n个数值相加结果为1，则使用 softmax 做输出层激活函数。通常在多项分布预测任务中使用。

## 隐藏层激活函数的选择

### sigmoid

和输出层选择原因类似，本身具有非线性特性，但是在层数较深的网络中，由于以下两个原因容易梯度消失：

1. 远离原点过饱和
   如果某个神经元输出的值远离原点（正负方向都会出现），会导致梯度趋于0，在梯度下降时无法有效更新参数
2. 0点处梯度过低
   就算模型很好的把输出控制在0点附近，层数过深时，因为其最大梯度为0.25，多层嵌套后会让梯度以 $0.25^n$ 的指数衰减

sigmoid一般用于较浅的网络中

### ReLu

ReLU的梯度在正区间恒定为1，不管多深的网络都不会梯度消失或者爆炸。但是如果某个模型输出了小于0的数，就会让梯度为0，无法在梯度下降中更新参数，出现神经元死亡的问题。需要注意的是，并不是说神经元输出小于0的数就会立刻死亡，因为就算本次输出小于0，该神经元可能在下轮训练的时候被其他训练数据救活（只是暂时休眠）。但是如果遇到某些极端数据使使神经元的参数更新太猛，这时候任何其他训练数据 $x$ 都会导致该神经元输出值小于0，这时候就可以宣判该神经元永久死亡了。

### Leaky ReLU / PReLU

在负半轴保留一个微小斜率（如 0.01），修复了 ReLU 负半轴梯度为 0 的缺陷，防止神经元永久“死亡”。

### GELU

结合了输入值的大致分布概率（高斯误差线性单元）。现代大模型（如 Transformer 架构）的标配激活函数，平滑且具备更强的特征捕获能力。

## 调试技巧

在模型调试过程中，我们可以先观察训练集和验证集 Loss 的变化趋势。

1. 训练Loss下降，验证Loss也在下降：模型正在学习，并且往训练目标靠近。
2. 训练Loss下降，验证Loss上升：可能过拟合，可增强训练数据。
3. 训练Loss和验证Loss都在高处停滞：模型学不动，可能欠拟合、模型容量不足。
4. Loss大幅震荡或者发散：可能是学习率过高、梯度不稳定。
5. 训练Loss和验证Loss都稳定，但训练效果不理想：可能是Loss函数和目标不一致。

训练方式：

把小说每一句话拆分成一条训练数据

现象：
模型永远输出空格，Loss居高不下

我的理解：

1. 输入为27维向量，隐藏层只有10维，会造成很严重的降维，可能限制模型对输入字符及历史上下文信息的表达能力，导致模型欠拟合。
2. 深度过深，导致tanh传递的时候撞到饱和区
3. 初始化的时候，权重偏大，把tanh撑大，导致Loss居高不下
4. 模型能力不足，退化成了边缘概率模型
