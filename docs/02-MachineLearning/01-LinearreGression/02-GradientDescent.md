# 梯度下降
虽然最小二乘法看起来很美好，理论上，只要目标函数（不一定是线性函数）对参数可导，我们都可以通过令偏导数为0来尝试求解，但是现实中这种理想的情况却很少。比如：
1. 怪异且无法求解的非线性方程组
我们遇到的是 $Y=ωX+b$ 这种非常理想的线性传感器。但如果遇到的是热敏电阻（测温度）、光敏电阻（测光强），它们的物理特性往往是非线性的，拟合函数里可能包含复杂的对数、指数（如 $e^{-X}$）或者高阶多项式。这时候你再去求偏导数并令其等于 0，得到的将是一组没有解析解的方程组。

2. 高维灾难与算力崩溃
就算所有传感器全都是完美的线性关系，如果要预测一个地方的 PM2.5，需要同时采集温度、湿度、风速、气压、车流量等多个特征指标，这时候直线的未知数参数变成了多个（$ω_1, ω_2, \dots, ω_n$）。求偏导后需要解一个n元线性方程组，使用常规的高斯消元法求解，时间复杂度为 $O(n^3)$ 。当n很大时（比如上万维特征），计算量会急剧膨胀，甚至导致内存溢出。

## 既然无法“一步到位”，那就“包抄迂回”

既然“一眼看出最低点”工程上行不通，我们可以引入一种更聪明、更省算力、更通用的近似迭代方案——**梯度下降（Gradient Descent）**。

我们可以想象一下蒙上双眼在下山。虽然我们无法一眼看清山谷的最低点在哪里，但我们可以用脚去感受当前踩着的地面：哪个方向的坡度最陡，我们就往哪个方向迈出一步。只要步子合适，多走几步，我们总能走到山脚。
