# 技巧篇

## 函数选择

虽然根据通用近似定理，在适当条件下，单隐藏层的网络只要有足够多的神经元就能以任意精度逼近目标函数，但这只说明模型具有相应的表达能力，并不保证训练算法一定能找到理想参数。loss函数决定了在训练时候的模型优化目标，如果损失函数的目标和我们的预测目标不一致，反而会导致模型远离最优参数。而激活函数则会影响模型的表达范围和优化难度。所以在机器学习中，我们通过如下技巧选择函数

### 损失函数

损失函数由模型输出结果的概率假设决定。如：

| 预测目标 / 概率假设        | 常用损失函数              | 说明                                                             |
| -------------------------- | ------------------------- | ---------------------------------------------------------------- |
| 连续值、独立同方差高斯噪声 | MSE                       | 假设模型输出与真实值之间的误差服从均值为 0、方差固定的高斯分布。 |
| 二元目标，伯努利分布       | Binary Cross-Entropy      | 对应伯努利分布的负对数似然                                       |
| 多分类目标，类别分布       | Categorical Cross-Entropy | 对应类别分布的负对数似然                                         |

### 输出层激活函数

输出层激活函数由模型输出结果的数学约束决定。如：

| 输出需求                   | 常用输出方式         | 注意事项                       |
| -------------------------- | -------------------- | ------------------------------ |
| 任意实数回归               | 线性映射（不加激活） | 输出范围为 $(-\infty,+\infty)$ |
| 二分类概率                 | Sigmoid              | 输出属于 $(0,1)$               |
| 多分类概率                 | Softmax              | 各类别概率之和为 1             |
| 值域为 $[-1,1]$ 的连续输出 | tanh                 | 输出是有界实数，不是天然的概率 |

### 隐藏层激活函数

由模型架构和优化特性决定，我们根据梯度传播与表达能力选择。如：

| 函数    | 优点                     | 缺陷 / 注意事项                    | 常见场景                   |
| ------- | ------------------------ | ---------------------------------- | -------------------------- |
| Sigmoid | 输出在 $(0,1)$，平滑     | 两端饱和时梯度接近零，输出非零中心 | 二分类输出层、部分门控结构 |
| tanh    | 输出在 $(-1,1)$，零中心  | 两端饱和时梯度接近零               | RNN、部分浅层网络          |
| ReLU    | 计算简单，正区间梯度稳定 | 负区间梯度为零，可能出现死神经元   | 传统 MLP、CNN              |

## 调试技巧

在模型调试过程中，我们可以先观察训练集和验证集 Loss 的变化趋势。

1. 训练Loss下降，验证Loss也在下降：模型正在学习，并且往训练目标靠近。
2. 训练Loss下降，验证Loss上升：可能过拟合，可增强训练数据。
3. 训练Loss和验证Loss都在高处停滞：模型学不动，可能欠拟合、模型容量不足。
4. Loss大幅震荡或者发散：可能是学习率过高、梯度不稳定。
5. Loss在稳定但训练效果不理想：可能是Loss函数和目标不一致。

## 语言模型训练技巧
这个问题的答案很反直觉：**初始 loss 高本身不会"产生"空格**，它只是"初始化过大"的症状；真正让输出变成空格的是另一个现象——**模型最后只学会了一元频率分布**。我做了几组量化实验，证据挺漂亮：

## 1. 决定性证据：loss 地板恰好等于一元熵

对语料统计每个字符的频率 $p$，算一元熵：

$$H(p) = -\sum_c p(c)\ln p(c) = \mathbf{2.8004}$$

而两个版本训练到后期，loss 都停在 **2.8019 / 2.8004** —— 几乎完全相等。同时 `argmax p` 就是空格（占 **20.2%**，是最常见的字符）。

也就是说：**模型只学会了一件事——"每个字符出现的频率"，完全没学会上下文**。一个纯频率模型（unigram）的最优预测就是空格，贪心解码自然全是空格。你可以把 2.80 当作这条语料的"废话基线"：loss 不显著低于它，就说明模型什么上下文都没学到。

## 2. 初始化的锅是怎么传导到这里的

`torch.randn`（std=1）直接初始化，问题有两层：

**输出层**：`out_layer` 是 $27\times11$，logit 的标准差 ≈ $\sqrt{11}\approx3.3$。softmax 在 std=3.3 的 logits 上极度尖锐——对错误类别的概率也能接近 1。所以初始 loss 是 **6.77**，远高于"完全乱猜"的 $\ln 27 = 3.30$。模型一开始不是"不知道答案"，而是"充满自信地答错"。

**隐藏层**：5 层 tanh 连乘，每次矩阵乘都把幅度放大。实测单步前向的预激活幅度：

| 层 | \|x\| 均值 | 最大 | \|tanh\|>0.99 占比 |
|---|---|---|---|
| layer0 | 1.21 | 4.05 | 4.8% |
| layer1 | 1.96 | 6.01 | 27.2% |
| layer2 | 2.72 | 9.19 | 41.7% |
| layer3 | 2.85 | 10.77 | 45.0% |
| layer4 | 1.76 | 7.36 | 21.4% |

中间层四成以上的单元已经贴着 ±1 饱和，$\tanh'(2.85)\approx 0.02$——梯度穿过这些单元时几乎被乘没了。**结果就是隐藏层基本学不动**（不管它算不算"梯度消失"，效果一样：时序特征一直是随机噪声）。

## 3. 于是只剩偏置可学

既然 hidden 特征是噪声，唯一能降低 loss 的参数就是输出层的偏置项 $\mathbf{b}$。最优解就是一元的对数频率：

$$p(c\mid\cdot) \approx \hat p_{\text{unigram}}(c)\quad\Rightarrow\quad \text{loss} \to H(\hat p) = 2.80$$

训练曲线上 loss 从 6.5 掉到 2.80 然后就平了，正是"输出层偏置学完、隐藏层一动不动"的形状。

## 4. 为什么会"越写越空"，而不是均匀乱码

两个叠加效应：

- **贪心 argmax**：频率模型里空格 20.2% 排第一，所以每一步都选空格。
- **自回归正反馈**：空格被喂回输入，hidden 状态落进同一个吸引域，下一步继续输出空格。teacher forcing 训练时每步喂的是真实字符，推理时喂的是自己的输出，二者分布不一致（exposure bias），一旦偏了就回不来。

## 5. 对照实验：换成 $1/\sqrt{\text{fan\_in}}$ 缩放初始化

其他都不改，只把每个参数乘上 $1/\sqrt{\text{fan\_in}}$：

| | 原始 randn | 缩放后 |
|---|---|---|
| 初始 loss | 6.77 | **3.38**（≈ ln27，符合"无信息"预期）|
| 训练 2000 步后 | 2.8019（= 一元熵）| **2.3443** |
| 续写 "alice" | `'alice                    '` | `'alice to to to to to to'` |

loss 突破了 2.80 这条"废话地板"，说明**瓶颈确实是初始化，不是容量**。续写变成 `to to to to` 是另一种典型退化（repetition collapse），弱 RNN + 贪心解码常见，但至少证明它学到了"介词后面常跟 to"这类二元/三元结构。

## 小结

> 初始 loss 高 → 说明 logits 幅度过大、tanh 饱和 → 隐藏层梯度被压平、学不到时序特征 → 只剩输出偏置可学 → 收敛到一元频率 → argmax 是最高频字符（空格）→ 自回归把空格喂回去，自我强化。

顺带一个实用技巧：**训练任何语言模型前先算一元熵作为 baseline**，loss 不比它低就说明模型还没学到上下文，比盯着生成结果靠谱得多。
