# 技巧篇

## 函数选择

虽然根据通用近似定理，在适当条件下，单隐藏层的网络只要有足够多的神经元就能以任意精度逼近目标函数，但这只说明模型具有相应的表达能力，并不保证训练算法一定能找到理想参数。loss函数决定了在训练时候的模型优化目标，如果损失函数的目标和我们的预测目标不一致，反而会导致模型远离最优参数。而激活函数则会影响模型的表达范围和优化难度。所以在机器学习中，我们通过如下技巧选择函数

### 损失函数

损失函数由模型输出结果的概率假设决定。如：

| 预测目标 / 概率假设        | 常用损失函数              | 说明                                                             |
| -------------------------- | ------------------------- | ---------------------------------------------------------------- |
| 连续值、独立同方差高斯噪声 | MSE                       | 假设模型输出与真实值之间的误差服从均值为 0、方差固定的高斯分布。 |
| 二元目标，伯努利分布       | Binary Cross-Entropy      | 对应伯努利分布的负对数似然                                       |
| 多分类目标，类别分布       | Categorical Cross-Entropy | 对应类别分布的负对数似然                                         |

### 输出层激活函数

输出层激活函数由模型输出结果的数学约束决定。如：

| 输出需求                   | 常用输出方式         | 注意事项                       |
| -------------------------- | -------------------- | ------------------------------ |
| 任意实数回归               | 线性映射（不加激活） | 输出范围为 $(-\infty,+\infty)$ |
| 二分类概率                 | Sigmoid              | 输出属于 $(0,1)$               |
| 多分类概率                 | Softmax              | 各类别概率之和为 1             |
| 值域为 $[-1,1]$ 的连续输出 | tanh                 | 输出是有界实数，不是天然的概率 |

### 隐藏层激活函数

由模型架构和优化特性决定，我们根据梯度传播与表达能力选择。如：

| 函数    | 优点                     | 缺陷 / 注意事项                    | 常见场景                   |
| ------- | ------------------------ | ---------------------------------- | -------------------------- |
| Sigmoid | 输出在 $(0,1)$，平滑     | 两端饱和时梯度接近零，输出非零中心 | 二分类输出层、部分门控结构 |
| tanh    | 输出在 $(-1,1)$，零中心  | 两端饱和时梯度接近零               | RNN、部分浅层网络          |
| ReLU    | 计算简单，正区间梯度稳定 | 负区间梯度为零，可能出现死神经元   | 传统 MLP、CNN              |

## 调试技巧

在模型调试过程中，我们可以先观察训练集和验证集 Loss 的变化趋势。

1. 训练Loss下降，验证Loss也在下降：模型正在学习，并且往训练目标靠近。
2. 训练Loss下降，验证Loss上升：可能过拟合，可增强训练数据。
3. 训练Loss和验证Loss都在高处停滞：模型学不动，可能欠拟合、模型容量不足。
4. Loss大幅震荡或者发散：可能是学习率过高、梯度不稳定。
5. Loss在稳定但训练效果不理想：可能是Loss函数和目标不一致。
