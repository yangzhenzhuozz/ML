# 全连接神经网络
通过上一章的内容，我们已经了解到多层神经网络的威力，这一章我们就直接上手实操吧。这次我们构造一个有3个输入，2层隐藏层的全连接（每一个神经元都和上一层的所有神经元连接）神经网络，结构如下：

```mermaid
flowchart LR
%% 输入
X1((x1))
X2((x2))
X3((x3))

%% 隐藏层
H11((h11))
H12((h12))
H13((h13))

H21((h21))
H22((h22))
H23((h23))

%% 输出
Y((y))

%% 全连接网络
X1 --> H11
X1 --> H12
X1 --> H13
X2 --> H11
X2 --> H12
X2 --> H13
X3 --> H11
X3 --> H12
X3 --> H13

H11 --> H21
H11 --> H22
H11 --> H23
H12 --> H21
H12 --> H22
H12 --> H23
H13 --> H21
H13 --> H22
H13 --> H23

H21 --> Y
H22 --> Y
H23 --> Y
```
